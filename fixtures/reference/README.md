# Reference assets

These are public development references, not garments supplied by a pilot store. They
have no gray card, measured physical color, owner approval, or qualified capture set.
Never include them as real-store observations in a Phase 0 report.

The exact source pages, licenses, authors and SHA-256 hashes are in `sources.json`.

- Tee front and back: **Béria L. Rodríguez @ Wikimedia Commons**,
  <https://commons.wikimedia.org/wiki/User:Beria>, CC BY-SA 3.0,
  <https://creativecommons.org/licenses/by-sa/3.0/>. Original photographs are unchanged.
  Any re-encoded versions keep the same license and attribution.
- Jeans: Oktaeder, released into the public domain.
- Mannequin: Quaternius (original), UMRAM/Bilkent University (posed version), CC0 1.0.
  The viewer centers and scales it to 1.75m for inspection; it is a stylized technical
  reference, not a verified anatomical model or a clothing block.

The canonical WebP copies used by the app are produced by the isolated image worker.
Do not copy raw uploads into the app's public directory.
