# 0010. The tier C sprite fallback is built in Phase 1, not later

**Status:** Accepted
**Date:** 2026-09-04

## Context

Not every phone that can open the storefront can run a WebGL viewer, and the phones that
cannot are disproportionately owned by the buyers this product exists to serve.

Two facts make this sharper than a normal progressive-enhancement question:

1. Most buyers arrive from Instagram, so they arrive inside the Instagram in-app browser.
   That WebView has its own memory limits, an unreliable WebGL context, and a habit of being
   killed and restored mid-session.
2. On low-end Android, exceeding GPU memory does not degrade gracefully. The context is
   lost and the canvas goes blank.

The natural instinct is to ship the 3D viewer and add a fallback later if complaints arrive.

## Decision

A three-tier device ladder, with tier C built in Phase 1 alongside the 3D viewer. Tier C is
a pre-rendered 36-frame sprite turntable with drag-to-spin, generated by the same Asset
Pipeline from the same solved meshes, supporting the same swap and layer interactions.

It is also the response to a lost WebGL context: fall back to tier C rather than showing a
blank canvas.

## Consequences

Pipeline work before it is provably needed, in the phase where scope discipline matters
most. This is a real cost and it is the reason the decision needs a record.

Three reasons it is still correct:

**A retrofitted fallback is always worse.** Built later, it becomes a degraded consolation
screen rather than a parallel experience. Built alongside, both tiers share the same layout,
the same controls, and the same interaction language, and the rendering degrades while the
product does not.

**There is no other safe answer to context loss.** Without tier C, a lost context in the
Instagram browser means a blank page during a purchase. That failure is invisible in
analytics and fatal to a pilot's numbers.

**It is nearly free once the assets exist.** The frames come from meshes the pipeline
already solved. The marginal cost is the sprite packing and one more code path in the viewer.

Tier C also gives a data-saver opt-in, which is worth having in a market where buyers watch
their data allowance closely.
